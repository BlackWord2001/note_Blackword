# 相关工具链

## cargo

### cargo clean
清理整个项目的构建缓存（包括 target/ 目录）
```bash
cargo clean
```

## 缓存清理工具（第三方）

是一个用于管理 Cargo 缓存的第三方工具，它可以帮助你查看、清理和优化 Rust 的包缓存，释放磁盘空间。

### cargo-cache

#### 安装 cargo-cache 工具
```bash
cargo install cargo-cache
```

#### 自动清理
```bash
cargo cache --autoclean  # 自动清理（保留最近使用的文件）
cargo cache -a # 简化写法
```
